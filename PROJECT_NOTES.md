# PC Builder Website
Goal: a website where people check PC part compatibility, see prices,
and use a "Builder" that asks budget and use-case and suggests a build.

Rules for the AI assistant:
- I do not know how to code. Explain what you did in plain English.
- Make small changes. Tell me exactly how to test each one.
- Keep everything free: static site, JSON data files, no paid services.
- Never delete my data files without asking.
- Keep the project organized in folders.

Stack: static site (HTML/CSS/JavaScript), JSON data in /data,
Python scripts in /scripts, GitHub Actions for scheduled updates.
